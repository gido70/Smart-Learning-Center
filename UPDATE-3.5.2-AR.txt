تحديث مركز التعلم الذكي 3.5.2
================================

هذا هو الإصدار المحلي المعتمد. لا تستخدم تحديث 3.6.0 السابق.
لا يوجد أمر SQL لهذا التحديث.

1. فك ضغط الحزمة وارفع محتوياتها إلى جذر مستودع GitHub مع استبدال الملفات القديمة.
2. انتظر تحديث GitHub Pages ثم افتح المنصة واضغط Ctrl+F5.
3. افتح المحاضرة واضغط «تعديل أو استبدال الخلاصة».
4. اضغط «إنشاء الخلاصة داخل المنصة».

كل عملية التلخيص والحفظ تتم داخل المنصة دون فتح ChatGPT ودون مفتاح API.
يعالج الإصدار التوقيتات الملتصقة مثل 44g ثانيةلاحظ، ويحوّل أشهر العبارات
المصرية إلى فصحى مبسطة، ثم ينتقي أهم الجمل للمراجعة السريعة.
