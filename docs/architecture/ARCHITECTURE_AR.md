# معمارية مركز التعلم الذكي

## مبدأ العمارة
المشروع مبنى متعدد الطوابق. كل طابق وحدة مستقلة، والأساسات المشتركة لا تُعدّل إلا بحذر.

## الطبقات
1. **Core:** التنقل، الإعدادات، الهوية، التسجيل.
2. **Modules:** وظائف المستخدم المستقلة.
3. **Services:** Supabase، الذكاء الاصطناعي، التفريغ، البحث.
4. **Shared:** المكونات والأدوات المشتركة.
5. **Tests:** اختبارات تمنع كسر ما يعمل.
