# قرارات استوديو التعلم المباشر

## المبدأ

المنصة تساعد عبدالرحمن على الفهم والتوثيق، ولا تتحدث أو تسأل بدلًا منه. كل اقتراح يجب أن يكون قابلًا للمراجعة والتعديل قبل استخدامه.

## مصادر التسجيل

- صوت المحاضرة هو المصدر الافتراضي، والميكروفون الشخصي متوقف افتراضيًا.
- لكل مصدر زر تشغيل وإيقاف وحالة مرئية.
- إنهاء الجلسة يوقف جميع مسارات الصوت والشاشة والتفريغ والالتقاط.
- التفريغ المختلط عربي/إنجليزي يعتمد على قدرات المتصفح، ويجب لاحقًا تقييم محرك تفريغ خلفي يدعم تبديل اللغات دون تعريض مفاتيح سرية.
- الترجمة الإنجليزية إلى العربية ميزة لاحقة تحتاج خدمة ترجمة معتمدة، ولا يجوز عرض ترجمة وهمية محلية.

## الشرائح والأسئلة

- مراقبة الشرائح تلقائية وسريعة مع تثبيت قصير ومنع التكرار.
- يوجد التقاط فوري يدوي عندما يكون المستخدم حاضرًا.
- يُفصل ما استُخرج من حديث المحاضر عما استُخرج من العرض.
- تُعرض الاقتراحات أفقيًا وبنص كامل، مع المصدر والتوقيت ورقم الشريحة.
- لا تُنشأ أسئلة لكل لقطة؛ تُقبل فقط الأسئلة والمداخلات المرتبطة بعلاقة أو غموض أو تطبيق أو تناقض مفيد.
- يمكن حفظ المقترح للمناقشة أو نسخه أو استبعاده.

## إنهاء الجلسة

- قرار واحد واضح: حفظ كمحاضرة مكتملة، أو حفظ كمسودة، أو حذف بعد تأكيد.
- بعد الحفظ تُغلق النافذة وتُنظف مساحة الجلسة الحالية.
- المسودة لا تُفرض على الجلسة التالية، ويمكن استعادتها بزر صريح.
- لا ينتقل نص أو شرائح أو اقتراحات من محاضرة إلى أخرى.

## مختبر المعرفة — النطاق المعتمد لاحقًا

الوظائف المختارة:

1. اسأل المحاضرة مع إظهار المصدر والتوقيت.
2. خريطة ذهنية للمفاهيم والعلاقات.
3. اختبار قصير مع تفسير الإجابات.
4. مجموعة شرائح مراجعة موجزة.
5. تقرير تطبيقي يحول المعرفة إلى مشروع أو قرار أو تجربة، وهو أولوية عالية.
6. خلاصة دقيقة للمفاهيم والروابط والأمثلة، وهي أولوية عالية.

الوظائف المستبعدة: الفيديو، البودكاست أو الملخص الصوتي، البطاقات التعليمية، المخطط البياني أو الإنفوجرافيك، وجدول البيانات.
