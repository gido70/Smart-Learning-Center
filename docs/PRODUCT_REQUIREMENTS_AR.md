# متطلبات مركز التعلّم والمعرفة الشخصي — عبدالرحمن

هذه الوثيقة هي المرجع الدائم للتطوير. لا تُحذف أي وظيفة قائمة عند تنفيذ بند جديد.

## الخصوصية
- المنصة شخصية وخاصة بحساب عبدالرحمن.
- لا تُحفظ كلمات مرور المنصات الخارجية ولا مفاتيح API في الواجهة.
- المشاركة الخارجية اختيارية ومؤقتة في ملفات السيرة والإنجاز فقط.

## التعلّم والمحاضرات
- تجميع أيام الدورة تحت كورس واحد بترتيب ثابت.
- خلاصة مفيدة لكل محاضرة، وخلاصة مجمعة للدورة دون تكرار.
- حفظ الروابط والأدوات والعروض والملاحظات والأسئلة وإتاحتها للبحث.
- الانتقال من جلسة مباشرة إلى محاضرة محفوظة دون إعادة الإدخال.
- الاحتفاظ برابط التسجيل الأصلي بدل تكرار ملفات الفيديو الكبيرة.
- دعم رفع العرض وملف Zoom Chat واستخراج الروابط في مرحلة الموارد.

## الشهادات والإنجازات
- الدراسية، العملية، المهنية، التدريبية، التكريم، العضويات، الجوائز والمشاركات.
- ربط اختياري بالدورة أو المشروع، مع صندوق للعناصر غير المرتبة.
- بحث وتصنيف حسب النوع والسنة والجهة والحالة.

## الأعمال والمشروعات
- سجل مستقل للمنصات، أدوات الذكاء، الأتمتة، الدراسات والتقارير والاستشارات.
- وصف الدور والنتيجة والروابط والتقنيات والأدلة، دون أسرار الاتصال.

## المخرجات المهنية
- إنشاء سيرة عربية أو إنجليزية حسب الغرض.
- ملف أعمال، ملحق شهادات، حقيبة تقديم، وصفحة مشاركة خاصة مؤقتة.

## ترتيب التنفيذ
1. سلاسل الدورات، الخلاصة المجمعة، أرشفة اللايف، حذف واستبدال الخلاصة.
2. العروض والشرائح وZoom Chat والروابط والبحث الشامل.
3. الشهادات والإنجازات والمشروعات.
4. السيرة الذاتية وملف الأعمال وحقيبة التقديم.
