# دليل مساحة المحاضرة الذكية

هذا الدليل يخص صفحة **مساحة المحاضرة الذكية** فقط، ويشرح تشغيلها دون الدخول في تفاصيل تقنية.

## البدء السريع

1. اختر مصدر المحاضرة: بث مباشر، ملف، رابط عام، منصة بحسابك، أو محاضرة محفوظة.
2. في البث المباشر شغّل **صوت المحاضرة** و**مشاركة العرض**، ثم اضغط **بدء الجلسة**.
3. عند انتهاء المحاضرة اضغط **إنهاء الجلسة**، ثم اختر الحفظ كمحاضرة مكتملة أو كمسودة أو حذف الجلسة.

## أهم الضوابط

- اترك زر **صوتي** متوقفًا لمنع تسجيل صوت الغرفة والميكروفون.
- زر **صوت المحاضرة** يلتقط صوت Zoom أو صوت الجهاز.
- زر **مشاركة العرض** يتيح متابعة العرض والتقاط الشرائح تلقائيًا.
- زر **تحديث الشريحة الآن** يأخذ لقطة فورية إذا تأخر الالتقاط التلقائي.
- استخدم **إيقاف مؤقت** عند الاستراحة، ثم **استئناف** للمتابعة.

## بعد انتهاء المحاضرة

- **حفظ كمكتملة:** للمحاضرة الصحيحة الجاهزة للدراسة.
- **حفظ كمسودة:** للاحتفاظ بالمحتوى ومراجعته أو إكماله لاحقًا.
- **حذف الجلسة:** للتجارب أو المحاضرات غير الصالحة، ولا يحدث إلا باختيار صريح.

تظهر المحاضرات المحفوظة في **مكتبة المحاضرات** أسفل الصفحة. ويمكن فتحها واستخدام **مختبر المعرفة** لإنشاء خلاصة موثقة، والبحث في المحاضرة، والخريطة الذهنية، والاختبار، ومراجعة الشرائح، والتقرير التطبيقي.
