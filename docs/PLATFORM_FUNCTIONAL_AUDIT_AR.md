# فحص وظائف منصة Smart Learning Center

**الإصدار المرجعي:** 3.5.2

**نطاق الفحص:** مراجعة ثابتة لجميع الواجهات وعناصر التفاعل، مع اختبار منطق استوديو التعلم المباشر محليًا. لم يتم الاتصال بـ Supabase أو تنفيذ SQL أو اختبار بيانات حقيقية.

## مفتاح التصنيف

- **تعمل:** لها منطق محلي قابل للتنفيذ ولا تتطلب خدمة غير متاحة.
- **تعمل جزئيًا:** الواجهة أو جزء من التدفق يعمل، لكن بعض النتائج تجريبية أو تعتمد على قدرة المتصفح.
- **غير مفعلة:** نموذج واجهة بلا منطق تشغيلي للزر أو الوظيفة الأساسية.
- **بها خطأ:** يوجد سلوك معروف غير صحيح في التنفيذ الحالي.
- **تحتاج Supabase أو خدمة خلفية:** لا يمكن إكمالها دون المصادقة أو التخزين أو المعالجة الخلفية.

## الأزرار غير المفعلة أو ذات النتيجة التجريبية

- زر الإشعارات لا يفتح مركز إشعارات.
- تحليل مستشار التعلم يعرض نتيجة نموذجية ولا يحلل الرابط فعليًا.
- لغة المصدر وإعدادات الاستوديو بلا نافذة إعدادات تشغيلية.
- نقطة التوقف في مساحة المحاضرة تحفظ توقيتًا نموذجيًا، وسؤال المساحة يعرض إجابة تجريبية.
- أزرار التعلم السريع والمشروعات والمراجعة ومصنع المحتوى والمحادثة بلا منطق المجال المطلوب.
- خريطة المعرفة والتحليلات والإعدادات تعرض بيانات ثابتة.

## حدود فحص الاستوديو

- لا يمكن للاختبار الآلي غير التفاعلي منح إذن شاشة أو ميكروفون؛ لذلك اختُبر منطق دورة الجلسة ومنع تكرار الشرائح والاستعادة وإيقاف المسارات برمجيًا، بينما يلزم اختبار متصفح يدوي للأذونات وجودة التسجيل.
- التقاط صوت النظام يتوقف على نظام التشغيل وChrome ونوع السطح المختار وتفعيل «مشاركة الصوت». لا تعرض المنصة حالة «الصوت متصل» إلا عند وجود مسار صوت حي.
- التسجيل المحلي ينتج ملف WebM عندما يدعم المتصفح `MediaRecorder`. لا تنتج المنصة تفريغًا وهميًا؛ يلزم مستقبلًا محرك Speech-to-Text معتمد أو خدمة خلفية.
- الاستعادة تحفظ البيانات الوصفية والشرائح والملاحظات، لكن المتصفح لا يسمح باستعادة أذونات أو مسارات الشاشة والميكروفون تلقائيًا؛ يجب إعادة اختيارها ثم متابعة الجلسة.
- الأرشفة البعيدة وربط السجل بالدورة واليوم يستخدمان الحقول الحالية دون تعديل مخطط البيانات، ويحتاجان Supabase متاحًا ومهيأً. يبقى الحفظ المحلي متاحًا عند غيابه.
