# live-learning

- الحالة: نموذج تجريبي جاهز لاختبار المتصفح قبل الاعتماد.
- الاعتماديات: واجهات MediaDevices وMediaRecorder وCanvas وLocalStorage في المتصفح.
- قاعدة البيانات: لا يحتاج التحكم في الجلسة إلى قاعدة بيانات؛ تبقى الأرشفة البعيدة اختيارية.
- الاختبارات: `node tests/live_session_controls_test.js`.
- المسؤوليات: ساعة الجلسة القابلة للإيقاف والاستئناف، مقارنة الشرائح، استعادة المسودة، وإيقاف مسارات الوسائط.
