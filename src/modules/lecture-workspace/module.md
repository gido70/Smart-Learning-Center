# مساحة المحاضرة الذكية الموحدة

تجمع هذه الوحدة مسار المحاضرة المباشرة والمسجلة في نقطة دخول واحدة من دون تغيير بيانات المحاضرات المحفوظة أو تنفيذ SQL.

## المصادر

- نافذة مباشرة مثل Zoom أو منصة أخرى.
- تسجيل فيديو أو صوت محلي.
- رابط YouTube أو رابط عام.
- محاضرة داخل منصة تتطلب تسجيل دخول؛ يتم الدخول في نافذتها الأصلية ولا تحفظ المنصة بيانات الحساب.
- محاضرة محفوظة سابقًا في المكتبة.

## الأدوات المحلية

- خلاصة مركزة.
- بحث موثق داخل المحاضرة.
- خريطة ذهنية.
- اختبار بإجابات وتفسيرات.
- شرائح مراجعة.
- تقرير تطبيقي يحول المعرفة إلى فرص بحث أو مشروع.

هذه الأدوات تستخرج من النص والشرائح المتاحة ولا تختلق إجابة عند غياب الدليل، ولا تستخدم مفتاح ذكاء اصطناعي خارجي.

## التوافق

- الرابط القديم `#replay` ينتقل إلى `#live` ثم إلى مكتبة المحاضرات داخل الصفحة الموحدة.
- عرض المحاضرة المحفوظة يبقى صفحة تفصيل داخل المسار نفسه، مع زر للعودة إلى المكتبة وزر لفتح أدوات المعرفة.
- لا تتغير جداول Supabase أو البيانات الحالية.
